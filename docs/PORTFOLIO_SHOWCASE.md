# Ashkan AQMS Enterprise v5 — Portfolio Showcase

## Visual direction
A high-contrast industrial command-center shell uses deep navy for navigation and a bright, spacious operational canvas. Cyan communicates telemetry/technology, green healthy acquisition, amber attention, and red alarms. The interface avoids a generic dark dashboard by keeping dense operational data on light surfaces with clear hierarchy.

## Product surfaces
- Enterprise Command Center
- Live Air Quality and AQI
- Analyzer Fleet Health
- Analyzer Configuration & secure credentials
- Driver Catalog
- Zero/Span Calibration Center
- Maintenance & Reliability Center
- Reports & Trend Intelligence
- Alarm & Audit History
- DAQ / Weather / UPS
- Remote Operations
- Serial/TCP Communication Lab
- Diagnostics
- Feature Center
- Settings and About/System Information

## Engineering differentiators
- RealHardware is the safe default.
- Simulation requires explicit opt-in.
- Disabled analyzers are excluded before polling and re-checked before a reading is accepted.
- Per-analyzer health registry records response time, failures and last quality.
- Vendor protocol migration is traceable through the retained legacy source archive.
- Driver validation status is explicit; source availability is not treated as hardware certification.
