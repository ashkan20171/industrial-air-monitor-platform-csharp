# v6 Enterprise Expansion

Ashkan AQMS v6 adds operator-facing capabilities that go beyond the supplied SadraAQMS reference source: Digital Twin, work-order planning, incident/shift handover, analytics workbench and an integration hub.

## Portfolio intent
The UI is deliberately structured like an industrial operations product: command center, asset fleet, live acquisition, maintenance, calibration, incidents, analytics, integration and diagnostics. The visual language uses a deep-navy operations shell with a high-contrast light canvas, restrained status colors and consistent Segoe UI typography.

## Safety and truthfulness
- Real hardware remains the default acquisition mode.
- Disabled analyzers are blocked before polling and re-checked before committing readings.
- Simulation is opt-in.
- The 35 supplied legacy source/reference files are retained, but vendor protocols are not represented as hardware-validated unless actually tested.
- Integration cards marked architecture-ready are extension boundaries, not active production servers.
